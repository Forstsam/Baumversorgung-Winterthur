Verlauf der Referenznähe

Die Normalwald-Linie ist ein Vergleichsmassstab, keine festgelegte optimale Zielstruktur für Stadtbäume. Das klassische Modell verteilt gleichmässig über Altersklassen bis zur gewählten Referenzlebensdauer; die alternative Verteilung berücksichtigt die im Modell verwendete allgemeine Alters-Ausfallkurve. Eine baumartenspezifisch optimale Altersstruktur wird hier nicht behauptet.
